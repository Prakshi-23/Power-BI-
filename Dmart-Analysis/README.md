# 🛒 Dmart Sales Analysis Dashboard

This project presents a **Sales Analysis Dashboard** for Dmart using **Power BI**. It provides insightful visualizations and key metrics to help stakeholders understand customer behavior, order patterns, and revenue trends.

## 📊 Dashboard Highlights

* **Total Orders**: 11K
* **Total Order Value**: ₹7.27 Million
* **Average Discount**: ₹736.10
* **Average Customer Ratings**: 3.00

### Visualizations Include:

* **Orders by City**
* **Orders by Shipping Mode** (Free, Priority, Express Plus)
* **Time Spent on Website by Age Group** (Young, Adult, Old)
* **Sum of MRP and Discount by Age Group**
* **Orders Over Time (2021–2023)**
* **Orders by Gender**
* **Payment Method and Subscription Filters**

## 📌 Key Insights

* Adults and Old customers contribute significantly to order volume.
* Most orders fall within the Free and Priority shipping categories.
* Website engagement varies by age group, influencing MRP and discount metrics.
* Gender-based purchasing trends are visualized for targeted marketing.

## 🛠 Tools Used

* **Power BI Desktop** – for data visualization and dashboard creation.
* **Excel/CSV Dataset** – assumed source for sales data.
* **Esri Maps Integration** – for geo-location-based insights.

## 📈 Future Enhancements

* Drill-down functionality by city and age group
* Integration with real-time data sources
