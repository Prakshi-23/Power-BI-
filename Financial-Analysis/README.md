# 📊 Financial Data Analysis Dashboard

This project presents a comprehensive financial data analysis using **Power BI**. The dashboard provides insights into sales, profits, discounts, and product performance across different countries, segments, and time periods.

## 🔍 Overview

The dashboard is designed to help stakeholders quickly understand:

* Total and average financial metrics
* Top-performing products and countries
* Sales trends over time
* Segment and discount band performance

## 📌 Key Metrics Displayed

* **Total Sales:** 118.73M
* **Total Profit:** 16.89M
* **Average Discount:** 13.15K
* **Max Sale Price:** 350
* **Max Manufacture Cost:** 260

## 🌍 Visual Insights

### 1. **Country-wise Sales and Profit**

* Visualizes the total sales and profit per country.
* Top 5 countries: United States, Canada, France, Germany, Mexico.

### 2. **Sales and Profit Over Time**

* Quarterly trend analysis from Q1 to Q4.
* Tracks both sales and profit growth across time.

### 3. **Top 5 Products by Profit**

* Highlights the best-performing products:

  * Paseo
  * VTT Amarilla
  * Velo
  * Montana
  * Others

### 4. **Segment-wise Sales**

* Compares performance across business segments: Government, Small Business, Enterprise, etc.

### 5. **Discount Band Distribution**

* Visualizes the proportion of sales falling under different discount categories: High, Medium, Low, None.
